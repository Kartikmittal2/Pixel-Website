# Pixel X Website

A static landing page for the Pixel X Android app.

## Files
- index.html — website
- style.css — visual design
- script.js — small interactions
- assets/logo.svg — Pixel X logo recreated from the Android project's supplied vector
- download/PixelX-release.aab — supplied Android App Bundle

## Run locally
Open index.html in a browser.

## Deploy
Upload the whole folder to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or another static host.

## Important
The supplied build is an `.aab` (Android App Bundle). It is normally distributed through Google Play / testing tracks rather than installed directly like an `.apk`.
