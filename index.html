One app.
Many possibilities.

Built as a native Android experience with a clean navy interface and practical tools for everyday use.

Smart Search

Search with Google, DuckDuckGo, Wikipedia, Bing, Brave, or YouTube. Pixel X remembers your recent searches and provides live suggestions.

Voice Search

Interactive Assistant

Ask Pixel X to do maths, tell the time, search the web, open installed apps, find videos, or open music.

BUILT FOR ANDROID

Simple on the surface.
Powerful underneath.

Pixel X is a native Android application built with Kotlin and Jetpack Compose. The app is designed around fast access: search something, speak a command, open an app, study a question, or start your music without jumping between tools.

Jetpack ComposeModern UI

STUDENT MODE

Turn a question
into an explanation.

Pixel X can read text from a photographed question on-device. You can correct the extracted text, calculate supported expressions, search the question, find a video explanation, save it to your question bank, or use your own Claude API key for AI tutoring.
